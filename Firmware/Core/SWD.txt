1. TỔNG QUAN HỆ THỐNG
1.1 Mô tả dự án
Bàn phím Dactyl Ergonomic là bàn phím cơ chia đôi (split keyboard) sử dụng vi điều khiển STM32F401/F411 (dòng STM32F4xx). Hệ thống gồm hai nửa (Master - Left, Slave - Right) giao tiếp với nhau qua UART và kết nối với máy tính qua USB HID.

│                    TÍNH NĂNG HỆ THỐNG                       │
├─────────────────────────────────────────────────────────────┤
│ • Split keyboard Master/Slave qua UART DMA                 │
│ • USB HID Composite (Keyboard 6KRO + Raw HID)              │

│ • Ma trận phím tối đa 8x6 mỗi nửa (hiện tại 4x4 demo)     │
│ • Debounce phần mềm per-key                                │
│ • CRC16 bảo vệ dữ liệu truyền thông                       │
│ • Independent Watchdog (IWDG) chống treo                    │
│ • LED chỉ thị trạng thái và layer                          │
│ • Raw HID endpoint cho giao tiếp host software              │
└─────────────────────────────────────────────────────────────┘

2.2 Cấu hình Clock Tree
text

HSE 25MHz ──► PLL ──► SYSCLK 84MHz
                         │
                         ├──► AHB  = 84 MHz  (DIV1)
                         ├──► APB1 = 42 MHz  (DIV2) → TIM2,TIM5 = 84MHz (×2)
                         ├──► APB2 = 84 MHz  (DIV1) → USART1 = 84MHz
                         └──► USB  = 48 MHz  (PLL/PLLQ = 336/7)

LSI 32kHz ──► IWDG (Prescaler=64, Reload=2000)
              → Timeout ≈ 64 × 2000 / 32000 = 4.0 giây

3.4.1 Master Main Loop
text

while(1)
│
├── HAL_IWDG_Refresh()              ← Feed watchdog
│
├── SplitComm_Process()             ← Parse RX DMA buffer
│   │                                  Send heartbeat ping
│   │                                  Check timeout
│   │
│   ├── Parse received bytes ──► _ProcessRxByte()
│   │                              │
│   │                              ├── SOF → TYPE → LEN → PAYLOAD → CRC
│   │                              │
│   │                              └── Valid packet → _HandlePacket()
│   │                                                    │
│   │                                                    ├── KEY_EVENT → Remote queue
│   │                                                    ├── KEY_STATE → Diff → Remote queue
│   │                                                    ├── PING → Send PONG
│   │                                                    └── PONG → Mark connected
│   │
│   ├── _MasterHeartbeat()          ← Send PING every 50ms
│   └── _CheckTimeout()            ← Disconnect if >100ms no RX
│
├── Process Local Events:
│   │
│   └── while (Matrix_GetEvent(&event))
│       └── KeyProcessor_HandleLocalEvent(&event)
│           │
│           ├── Resolve keycode from LEFT keymap
│           ├── Handle basic key (modifier / normal)
│           └── Handle layer action (MO/TG/DF)
│
├── Process Remote Events:
│   │
│   └── while (SplitComm_GetRemoteEvent(&remote_event))
│       └── KeyProcessor_HandleRemoteEvent(&remote_event)
│           │
│           ├── Resolve keycode from RIGHT keymap
│           ├── Handle basic key
│           └── Handle layer action
│
├── USB HID Report:
│   │
│   └── if (USBD_HID_KeyboardReady())
│       └── HIDReporter_SendIfChanged()
│           │
│           ├── Check KeyProcessor changed flag
│           ├── Build HID_KeyboardReport_t
│           ├── Compare with last report
│           ├── Send via USBD_HID_SendKeyboardReport()

│
├── Raw HID Check:
│   │
│   └── USBD_HID_GetRawData() → (reserved for future)
│
└── LED Layer Indicator:
    │
    └── layer_state & 0x02 ? LED_LAYER1 = ON : OFF

3.5 Interrupt Architecture
text

┌───────────────────────────────────────────────────────────────┐
│                    INTERRUPT PRIORITY MAP                      │
├────────────────────┬──────────┬────────────────────────────────┤
│  Interrupt         │ Priority │ Handler                        │
├────────────────────┼──────────┼────────────────────────────────┤
│  TIM2              │    1     │ Matrix_Scan() + Debounce       │
│  DMA2_Stream2 (RX) │    2     │ UART RX DMA (circular)         │
│  DMA2_Stream7 (TX) │    2     │ UART TX DMA complete           │
│  USART1            │    2     │ UART Error + IDLE detection    │
│  OTG_FS            │    3     │ USB device events              │
│  TIM5 (HAL Tick)   │   15     │ HAL_IncTick() - 1ms timebase   │
└────────────────────┴──────────┴────────────────────────────────┘

Nguyên tắc:
• Matrix scan (TIM2) ưu tiên cao nhất → đảm bảo quét đều 1ms
• UART DMA ưu tiên 2 → đảm bảo nhận/gửi split data kịp thời
• USB ưu tiên 3 → xử lý USB events sau matrix và UART
• HAL Tick ưu tiên thấp nhất → không ảnh hưởng real-time

4.1.3 Thuật toán quét ma trận
text

Matrix_Scan() [Gọi từ TIM2 ISR, mỗi 1ms]
│
├── _Matrix_ScanRaw()
│   │
│   │  FOR mỗi row (0..3):
│   │    ├── _Row_DriveLow(row)     ← BSRR reset bit (active LOW)
│   │    ├── NOP × 8                ← Chờ tín hiệu ổn định (~100ns)
│   │    ├── _Read_Columns()        ← Đọc IDR, bit=0 nghĩa pressed
│   │    │   │
│   │    │   │  FOR mỗi col (0..3):
│   │    │   │    if (!(IDR & col_pin)) → col_state |= (1<<col)
│   │    │   │
│   │    │   └── return col_state (bitmask)
│   │    │
│   │    ├── raw[row] = col_state
│   │    └── _Row_DriveHigh(row)    ← BSRR set bit (deactivate)
│   │
│   └── [Kết quả: raw[0..3] chứa bitmask các phím đang nhấn]
│
└── _Matrix_ApplyDebounce()
    │
    │  FOR mỗi (row, col):
    │    │
    │    ├── raw_pressed = (raw[row] >> col) & 1
    │    │
    │    ├── IF debounce.status == STABLE:
    │    │   │
    │    │   └── IF raw_pressed ≠ stable_state:
    │    │       ├── stable_state = raw_pressed
    │    │       ├── status = DEBOUNCING
    │    │       ├── timer = DEBOUNCE_TIME_MS (5)
    │    │       ├── Update debounced[row] bit
    │    │       ├── changed = true
    │    │       └── _Matrix_GenerateEvents(row, col, raw_pressed)
    │    │           │
    │    │           └── Push KeyEvent to queue
    │    │
    │    └── IF debounce.status == DEBOUNCING:
    │        └── [Bỏ qua, timer đếm xuống trong DebounceTask]
    │
    └── [Note: Đây là "eager debounce" - thay đổi ngay, khoá input
         trong DEBOUNCE_TIME_MS]
4.1.4 Đặc điểm debounce
text

Phương pháp: Eager Debounce (phản hồi ngay, khóa sau)

Timeline khi nhấn phím:
────────────────────────────────────────────────────
t=0ms  : raw thay đổi 0→1
         → Cập nhật debounced ngay lập tức
         → Tạo PRESSED event
         → Đặt timer = 5ms, status = DEBOUNCING

t=1ms  : DebounceTask: timer-- (timer=4)
         ScanRaw: đọc raw, nhưng ApplyDebounce bỏ qua
                  vì status = DEBOUNCING

t=2ms  : timer-- (timer=3), bỏ qua

t=3ms  : timer-- (timer=2), bỏ qua

t=4ms  : timer-- (timer=1), bỏ qua

t=5ms  : timer-- (timer=0), status = STABLE
         → Bắt đầu chấp nhận thay đổi mới

Ưu điểm: Phản hồi tức thì (0ms latency)
Nhược điểm: Nếu noise xảy ra đúng lúc chuyển trạng thái,
            có thể ghi nhận sai 1 lần. Tuy nhiên với phím cơ
            thực tế, rất hiếm khi xảy ra.
────────────────────────────────────────────────────

4.2.6 Layer Actions Detail
text

MO(layer) - Momentary: Active khi giữ, deactive khi thả
──────────────────────────────────────────────────────────
  Encoding: 0x1000 | (0x0 << 8) | (layer << 4)
  Ví dụ: MO(1) = 0x1010

  PRESS:   layer_state |= (1 << layer)   → Bật layer
  RELEASE: layer_state &= ~(1 << layer)  → Tắt layer
           layer_state |= 0x01           → Đảm bảo Layer 0 luôn bật

TG(layer) - Toggle: Đảo trạng thái khi nhấn, không làm gì khi thả
──────────────────────────────────────────────────────────
  Encoding: 0x1000 | (0x1 << 8) | (layer << 4)
  Ví dụ: TG(1) = 0x1110

  PRESS:   layer_state ^= (1 << layer)   → Toggle layer
           layer_state |= 0x01           → Đảm bảo Layer 0
  RELEASE: (không làm gì)

DF(layer) - Default: Chuyển sang layer duy nhất
──────────────────────────────────────────────────────────
  Encoding: 0x1000 | (0x2 << 8) | (layer << 4)
  Ví dụ: DF(2) = 0x1220

  PRESS:   layer_state = (1 << layer)    → Chỉ bật layer này
  RELEASE: (không làm gì)

4.3 Split Communication (split_comm.c/h)
4.3.1 Mục đích
Truyền nhận dữ liệu phím giữa Master và Slave qua UART với DMA, có kiểm tra CRC16 và cơ chế heartbeat/timeout.

4.3.2 Packet Format
text

┌─────┬──────┬──────┬──────────────────┬───────┬───────┐
│ SOF │ TYPE │ LEN  │    PAYLOAD       │ CRC_L │ CRC_H │
│ 1B  │ 1B   │ 1B   │    0..16 bytes   │ 1B    │ 1B    │
└─────┴──────┴──────┴──────────────────┴───────┴───────┘

SOF:      0xAA (Start of Frame)
TYPE:     Packet type identifier
LEN:      Payload length (0..16)
PAYLOAD:  Variable length data
CRC:      CRC16-CCITT over [TYPE + LEN + PAYLOAD]
          Polynomial: 0x1021, Init: 0xFFFF

Tổng kích thước: 3 + LEN + 2 = 5..21 bytes
Max packet: SPLIT_MAX_PACKET_SIZE = 21 bytes

──────────────────────────────────────────────
  Mỗi 50ms (SPLIT_HEARTBEAT_MS):
    → Gửi PING packet (no payload)
    → last_heartbeat_tick = now

Slave Response:
──────────────────────────────────────────────
  Nhận PING → Gửi PONG packet (no payload)

Timeout Detection:
──────────────────────────────────────────────
  Mỗi vòng lặp SplitComm_Process():
    IF status == CONNECTED:
      elapsed = now - last_rx_tick
      IF elapsed > 100ms (SPLIT_TIMEOUT_MS):
        status = DISCONNECTED

Auto Reconnect:
──────────────────────────────────────────────
  Bất kỳ packet hợp lệ nào nhận được:
    last_rx_tick = now
    IF status == DISCONNECTED:
      status = CONNECTED
4.3.8 Error Recovery
text

HAL_UART_ErrorCallback():
│
├── Clear error flags: ORE, NE, FE
│
├── Reset RX state machine → WAIT_SOF
│
├── Reset DMA read position → 0
│
├── HAL_UART_DMAStop()
│
├── HAL_UART_Receive_DMA() restart
│
└── rx_error_count++

Các lỗi UART được xử lý:
• ORE (Overrun Error): DMA không kịp → clear & restart
• NE  (Noise Error):   Nhiễu đường truyền → clear
• FE  (Framing Error): Sai format frame → clear

4.4 HID Reporter (hid_reporter.c/h)
4.4.1 Mục đích
Xây dựng USB HID Keyboard report từ trạng thái KeyProcessor và gửi qua USB endpoint khi có thay đổi.

4.4.2 Hoạt động
text

HIDReporter_SendIfChanged(pdev):
│
├── IF !KeyProcessor_HasChanged() → RETURN
│
├── Get KeyProcessorState_t
│
├── Build current_report:
│   │
│   ├── report_id  = 0x01 (KEYBOARD)
│   ├── modifiers  = state->modifiers
│   ├── reserved   = 0x00
│   └── keycodes[6] = state->pressed_keys[0..5]
│       (zero-pad nếu ít hơn 6 phím)
│
├── IF current_report ≠ last_report:
│   │
│   ├── USBD_HID_SendKeyboardReport(pdev, &current_report)
│   │
│   └── IF success:
│       └── last_report = current_report
│
└── KeyProcessor_ClearChanged()

Note: So sánh toàn bộ struct (memcmp) trước khi gửi
      → Tránh gửi report trùng lặp
      → Giảm tải USB bus

│                    IWDG Configuration                     │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  Clock:      LSI ≈ 32 kHz                                │
│  Prescaler:  64                                          │
│  Reload:     2000                                        │
│                                                          │
│  Timeout = (Prescaler × Reload) / LSI_freq               │
│         = (64 × 2000) / 32000                            │
│         = 4.0 giây                                       │
│                                                          │
│  Feed: HAL_IWDG_Refresh() ở đầu main loop               │
│                                                          │
│  Khi nào watchdog reset xảy ra:                          │
│  • Main loop bị treo > 4 giây                            │
│  • USB enumeration fail và loop không chạy               │
│  • Hard fault xảy ra                                     │
│  • UART DMA deadlock                                     │
│                                                          │
│  Khởi tạo sau SplitComm_Init() để tránh reset            │
│  trong quá trình USB enumeration (có thể > 1s)           │
│                                                          │
└──────────────────────────────────────────────────────────┘
8.2 Error Handler
text

Error_Handler():
  __disable_irq()
  while(1) { }  ← Infinite loop, chờ watchdog reset

Các nguồn gọi Error_Handler():
  • HAL_RCC_OscConfig() fail
  • HAL_RCC_ClockConfig() fail
  • HAL_TIM_Base_Init() fail
  • HAL_UART_Init() fail
  • HAL_IWDG_Init() fail
  • HAL_PCD_Init() fail
  • USBD_Init() / USBD_RegisterClass() / USBD_Start() fail
  • HAL_DMA_Init() fail

10.2 Build cho Master vs Slave
text

Cùng codebase, chỉ thay đổi 1 define:

Master (Left Half):
  #define KEYBOARD_ROLE  KEYBOARD_ROLE_MASTER  (0)
  → Bật: USB Device, KeyProcessor, HIDReporter
  → Chạy: Process local + remote events, gửi HID report

Slave (Right Half):
  #define KEYBOARD_ROLE  KEYBOARD_ROLE_SLAVE   (1)
  → Tắt: USB Device, KeyProcessor, HIDReporter
  → Chạy: Forward local events qua UART, respond PING

Conditional compilation dùng #if:
  #if (KEYBOARD_ROLE == KEYBOARD_ROLE_MASTER)
    // Master-only code
  #else
    // Slave-only code
  #endif
